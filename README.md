# Summary

This project was completed as part of my final year at university. It builds a simulation of a 2x2 array of parallel CPUs with wraparound between the edges (known as a `torus' structure), as well as a common shared memory unit. It can then run various APSP algorithms (namely Dijkstra's, Fox-Otto and Cannon's algorithms), and outputs to the console the time taken to run each one in milliseconds, based on a virtual measurement of each operation in each algorithm.
